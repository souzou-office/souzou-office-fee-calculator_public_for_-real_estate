# 登記費用 概算シミュレーター（不動産会社様向け）

固定資産税評価額などを入力するだけで、司法書士報酬・登録免許税・実費の概算がその場で確認できる1画面のツールです。
提携不動産会社に URL を渡し、見積依頼の前に金額の目安を自分で把握してもらう用途を想定しています。

報酬テーブル・単価は事務所の既定値をコードに固定で内蔵しており、利用者側で設定を変更することはできません。

## 入力項目

- 登記の内容（売買＝所有権移転 / 新築＝所有権保存）
- 土地・建物の固定資産税評価額（新築は建物の課税標準額）
- 不動産の個数、区分建物（マンション）
- 住宅用家屋証明書（なし / 一般住宅 / 長期優良・低炭素）
- 住宅ローン（抵当権設定）の債権額
- 任意：売主側の抵当権抹消・住所変更

## 出力

- 買主負担：報酬（税抜・消費税・税込）、登録免許税、実費（登記事項証明書・郵送費）、合計
- 売主負担（任意入力時）：報酬、登録免許税、合計
- 登録免許税の計算過程、概算書の印刷・PDF保存

## 事務所側の設定

`src/estimateConfig.js` で事務所名・連絡先・消費税率・謄本の自動計上・郵送費を変更できます。
報酬テーブルや加算単価は `src/calc.js` の既定値（`DEF_FT` / `DEF_UNIT` / `DEF_SURCHARGES`）を編集してください。

## 開発

```bash
npm install
npm run dev
npm test
```

## デプロイ

`main` ブランチに push すると GitHub Actions 経由で GitHub Pages に自動デプロイされます。

Settings → Pages → Source を **GitHub Actions** に設定してください。
公開 URL のパスはリポジトリ名に合わせて `vite.config.js` の `base` で指定しています。
